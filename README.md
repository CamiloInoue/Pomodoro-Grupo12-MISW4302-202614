## Cómo ejecutar el proyecto web (pomodoro-web)

Primero se necesita tener instalado Node.js en su versión 22.22.3 o superior, o la versión 24.15.0 o superior, ya que Angular CLI 22 no arranca con versiones intermedias como la 24.14.x. Node incluye npm, así que no hace falta instalar nada más. Una vez instalado Node, hay que entrar a la carpeta del proyecto e instalar las dependencias con "cd pomodoro-web" seguido de "npm install". Con las dependencias instaladas, se levanta el servidor de desarrollo con "npm start" y se abre el navegador en http://localhost:4200. Cualquier cambio que se haga en el código se recarga automáticamente en el navegador, sin necesidad de reiniciar el servidor. Si al correr "npm install" o "npm start" en Windows sale un error que dice que la ejecución de scripts está deshabilitada (running scripts is disabled on this system), es un tema de la política de seguridad de PowerShell, no del proyecto, y se soluciona usando "npm.cmd" en vez de "npm" (por ejemplo "npm.cmd install"), o corriendo los mismos comandos desde cmd.exe en lugar de PowerShell. Para correr las pruebas automatizadas del proyecto se usa "npm test".
