## Cómo ejecutar el proyecto web (pomodoro-web)

Primero se necesita tener instalado Node.js en su versión 22.22.3 o superior, o la versión 24.15.0 o superior, ya que Angular CLI 22 no arranca con versiones intermedias como la 24.14.x. Node incluye npm, así que no hace falta instalar nada más. Una vez instalado Node, hay que entrar a la carpeta del proyecto e instalar las dependencias con "cd pomodoro-web" seguido de "npm install".
